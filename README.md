# Inbox Scout

Inbox Scout is a local-first Gmail inbox cleanup assistant.

## Safety Rules

- Starts read-only.
- No deleting by default.
- No archiving by default.
- No sending replies by default.
- No Gmail label modification until later phases.
- Protected emails must require manual review.

## Current Phase

Phase 0: Project setup.

## Planned Direction

1. Project setup
2. Gmail read-only connection
3. Basic inbox fetcher
4. Rule-based classifier
5. Local AI classifier
6. Report mode
7. Review queue
8. Gmail label mode
9. Approve-to-archive mode
10. Atlas integration later
